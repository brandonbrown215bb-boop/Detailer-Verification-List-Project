# Architecture Decisions

Create numbered ADRs for decisions whose reasons need to survive the implementation.

## ADR standard

Use the next zero-padded number. New records should contain **Context**, **Decision(s)**, and **Consequences**; add dated addenda rather than rewriting the historical decision. Status is `Proposed`, `Accepted`, or `Superseded`; a superseding ADR must link to the earlier record.

Historical aliases: early planning material may call ADR 0002 “rules-engine selection” and ADR 0003 “hybrid Excel read strategy.” The canonical records are the filenames linked below.
